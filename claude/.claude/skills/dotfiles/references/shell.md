# Shell (`sh` package)

Both `~/.zshrc` (primary, CachyOS default) and `~/.bashrc` source the **same** modular files, so everything in
`~/.config/sh/` must work in both shells.

## Load order

`.zshrc`: p10k instant prompt → `~/.config/sh/cachyos.zsh` (oh-my-zsh, p10k, zsh plugins, fzf, command-not-found)
→ modular loop → tool hooks (`fj`, `mise`, `zoxide`, `direnv`, `atuin`).

`.bashrc`: git-completion + git-prompt → modular loop → tool hooks (`fj`, `zoxide`, `direnv`, cargo, `mise`,
sdkman, `atuin`).

Modular loop, in this order:

```
paths → env → configs → completions → funcs → aliases → prompt
```

For each `<cfg>`: source `~/.config/sh/<cfg>/default.sh` (or `~/.config/sh/<cfg>.sh` when there is no
directory, e.g. `prompt.sh`), then `~/.config/sh/<cfg>/$HOSTNAME.sh` if it exists. zsh's `$HOST` is copied
into `HOSTNAME` first.

Hosts with overrides: `blade`, `phoenix`, `scipio`, `DE25TAAL1920S9` (work WSL). Run `hostname` to know which
one is current. Host files only exist for some categories — create `<cfg>/<host>.sh` as needed; no
registration step.

## Where to put things

| Want | File | Notes |
|---|---|---|
| alias for all hosts | `sh/.config/sh/aliases/default.sh` | put under the matching `## SECTION` header (QUICKIES, VIM, DIRS, UPDATE/UPGRADE, GIT, DOCKER, RSYNC + SSH, YOUTUBE, Other tools — alphabetical there, BUILD / COMPILATION, C++) |
| host-only alias (dir jumps, mounts) | `sh/.config/sh/aliases/<host>.sh` | |
| shell function | `sh/.config/sh/funcs/default.sh` | POSIX-ish `name() { ... }`, use `local`, print errors to `>&2` and `return 1` |
| exported env var | `sh/.config/sh/env/default.sh` or `env/<host>.sh` | |
| PATH entry | `sh/.config/sh/paths/default.sh` | must add to **both** branches (see below) |
| history / shell options | `sh/.config/sh/configs/default.sh` | |
| completion | `sh/.config/sh/completions/default.sh` | split by `$BASH_VERSION` / `$ZSH_VERSION` |
| bash prompt | `sh/.config/sh/prompt.sh` | zsh uses powerlevel10k → `sh/.p10k.zsh` (generated by `p10k configure`, edit sparingly) |
| zsh-only plugin / OMZ plugin | `sh/.config/sh/cachyos.zsh` | `plugins=(git fzf extract)` |
| new tool `eval "$(x init ...)"` | `sh/.zshrc` **and** `sh/.bashrc` | keep the two in sync, guard with `command -v` |
| login-shell stuff | `sh/.zprofile` / `sh/.profile` | |

## Conventions

- Guard optional tools: `if command -v eza &>/dev/null; then ... fi`. Pick fallbacks the way `aliases/default.sh`
  does for `bat`/`batcat` and `eza`/`exa`/`ls`.
- Shell-specific code: `if [ -n "$ZSH_VERSION" ]; then ... elif [ -n "$BASH_VERSION" ]; then ... fi`.
- PATH in `paths/*.sh`:
  ```sh
  if [ -n "$ZSH_VERSION" ]; then
      path+=("$HOME/new/bin")
      typeset -U path
  elif [ -n "$BASH_VERSION" ]; then
      export PATH=$PATH:~/new/bin
  fi
  ```
- Temporary helper vars get `unset` afterwards (`_ls_cmd`, `_nproc` pattern).
- Use `alias name='...'` with single quotes unless expansion at definition time is intended.
- Before adding an alias, check it doesn't shadow a command or existing alias:
  `rg -n "alias <name>=" ~/.dotfiles/sh` and `zsh -ic 'whence -va <name>'`.

## Validate & apply

```bash
zsh -n ~/.dotfiles/sh/.config/sh/aliases/default.sh     # syntax (zsh)
bash -n ~/.dotfiles/sh/.config/sh/aliases/default.sh    # syntax (bash)
zsh -ic 'alias <name>; whence -v <fn>' 2>&1 | tail -3   # confirm it loads in a fresh interactive shell
```

User applies with `src` (re-sources `~/.zshrc`) or a new terminal.

## Known quirks (fix only if asked)

- `env/default.sh` sets `EDITOR=/usr/bin/vim` for bash only; `env/blade.sh` sets `EDITOR=nvim`.
- `funcs/bash_git.sh` and `ext_functions/git-completion.bash` are vendored upstream git scripts — don't edit.
